# STRM management UI contract

- The authenticated STRM routes are `/strm` and `/strm/files/:id`. They display only registered generation data through the generated OpenAPI types. URL parameters own library ID, name filter, sort and pagination. Returning to the list restores its filters. [Application routes](../../../frontend/src/app/app.tsx)
- Media-library details use the same registry query for their STRM total. The 「查看 STRM」 link selects the library by persistent ID. The full-sync preview submits `type: "strm"` through the task center with session CSRF and opens the accepted task. Preview shows saved source and output settings. Eligibility reflects enabled state, STRM output, 302 mode, the saved playback address, and backend task capabilities. History reads the same task list filtered by `type=strm` and `library_id`. [Execution preview](../../../frontend/src/features/media-library/library-execution-preview-page.tsx)
- The media-library detail card uses the registry `total` for 「总数量」 and 「已生成」. Display 「待处理」 and 「失败」 as `—` until a library-wide count exists. The execution timeline shows up to four actual records from the scoped task list. Each entry links to its task, uses the actual counts and duration, and shows a compact Shanghai-local date. [Media-library detail](../../../frontend/src/features/media-library/library-detail-view.tsx)
- Preview calls `GET /api/v1/libraries/{id}/full-sync-preview` for bounded sampling (3 directories / 5 actual requests including retries / 15 seconds / 20 samples, at most 200 entries per page). Decode required `mode=sample` and all six `stop_reason` values including `sample_limit`. Label observed counts as sampling results, explain the actual stopping reason and say “本次抽样未发现” for empty samples. Empty/partial samples do not imply an empty library and do not disable otherwise eligible confirmation. Confirmation requires current revision and output `ready`/`will_create`; the worker then performs a fresh full scan. Use an independent `full-sync-preview` query key and static stale policy; no automatic retry, focus/reconnect/poll or broad library invalidation may rescan. Entering/revision change and explicit refresh can request another sample. Leaving cancels in-flight work.
- The registry and setup surfaces distinguish loading, empty, failure, missing local output and changed content. File rows show 未检查 for playback and validity before a check module exists. Preview registered contents as read-only text. [STRM feature](../../../frontend/src/features/strm-management/)
- The STRM list uses HeroUI component defaults. Use Tailwind utilities on layout wrappers for spacing, breakpoints and table overflow. Keep the list keyboard-operable in both themes. Table row activation, filename links and the actions menu open details and preserve the list query. Task change events invalidate registry reads in the shared query cache.
- Use the filtered API total for the file and pending counts while validity is unavailable. Leave valid and abnormal counts unknown. Disable the status and time filters and batch maintenance until the API provides those capabilities. Selection belongs to the current page. CSV export uses selected rows when present and all current-page rows otherwise. Export only relative paths, library names and generated times.
- Browser coverage exercises full-sync preview and confirmation, returned task navigation, real count/filter linkage, list paging, selection, export, keyboard detail navigation, and empty/error states. [STRM Playwright coverage](../../../frontend/e2e/strm-management.spec.ts)

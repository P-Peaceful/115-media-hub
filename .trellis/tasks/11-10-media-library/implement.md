# 实施计划

实施前需完成规划审阅和任务启动；本文件本身不授权开始实现。

1. 阅读前后端、跨层及云盘相关规范，核对设计图配置项与可用选项，定义字段、默认值、校验和 API 契约；生成前后端类型。
2. 添加 SQLite 迁移、媒体库仓储与服务，提供有鉴权和 CSRF 保护的管理接口，确保配置持久化、删除只操作配置及错误处理符合约定。
3. 实现媒体库首页、创建、详情和编辑，复用 115 目录浏览；完成两列及响应式布局，区分配置启用状态与未实现的运行状态。
4. 覆盖创建/编辑/启停/删除、字段往返、输入错误、授权或目录读取失败、空列表及不可用操作；验证迁移、认证/CSRF 和删除不触碰文件。
5. 运行 `make check`、适当的 `make test-e2e`；必要时运行集成和构建验证。核对生成契约、视觉布局、键盘操作、主题及窄屏状态。
6. 检查需求和跨层一致性，更新项目规范。迁移及契约为主要回滚点，回滚时保留用户配置并按项目迁移策略处理数据。

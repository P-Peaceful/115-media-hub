# 媒体库管理与配置

## 目标

让用户管理基于 115 网盘目录的媒体库配置，为后续扫描、同步和 STRM 生成功能提供基础。页面参考[设计图](research/media-library-design.png)。

## 范围与要求

- 提供媒体库首页、新建页、详情页和编辑配置入口，接入现有导航；首页宽屏时一行两张卡片，窄屏布局保持可读和可操作。前端适用的交互与展示组件使用项目固定的 HeroUI v3 组件及其自带样式；不要用自定义 CSS 覆写组件样式，需要样式或布局调整时使用 Tailwind CSS。
- 首页支持查看和按启用状态筛选媒体库，展示名称、媒体类型、启用状态、绑定目录和本地输出目录，并提供编辑、启用/暂停及删除操作。删除需确认，仅删除媒体库配置，不删除网盘或本地文件。
- 新建和编辑支持设计图中的基本信息、115 目录选择、媒体类型、输出选项、本地输出目录、目录结构、路径映射、STRM 链接选项及文件规则。以现有 115 目录浏览能力选择目录；配置项需校验、保存并可重新编辑。
- 详情页展示已保存的媒体库概况、启用状态、绑定目录与输出配置。启用/暂停是配置状态，不能表述为同步服务正在运行。
- 全量同步、增量同步、执行预览、扫描、实际 STRM/NFO 生成、执行记录和统计计算不在本期实现；相关入口或区域如保留，明确显示不可用或暂无数据，不展示虚构结果或把未知值显示为零。
- 应处理空列表、加载、验证错误、保存失败、目录授权不可用及目标不存在等状态；重启后配置仍可读取。

## 验收标准

- [ ] 足够宽的首页每行显示两个媒体库卡片；窄屏下内容和操作可用。
- [ ] 用户可创建、查看、编辑、启用/暂停和经确认删除媒体库，刷新或重启后保存结果一致；删除配置不删除任何网盘或本地文件。
- [ ] 创建与编辑时可从已授权的 115 网盘选择目录；授权或目录读取失败时有清晰反馈，配置字段的校验错误可见。
- [ ] 所有展示的配置均能保存并在编辑或详情中正确恢复；筛选与持久化启用状态一致。
- [ ] 未实现的执行操作不可触发，统计和执行记录不显示示例数据或虚假成功。
- [ ] 管理接口遵循现有登录、CSRF、错误和 OpenAPI 约定；相关前后端测试覆盖主要管理流程和失败状态。

## 范围外与约束

- 任务调度、扫描与同步、文件生成/修改/清理、播放解析、真实执行记录与统计属于后续工作。
- 项目已有 115 只读目录浏览；现有媒体库导航尚未启用。设计图标注“媒体库（上）”，其余设计未提供。
- 设计图的示例名称、数字和时间不是产品数据。遵守项目现有任务持久化、文件归属和冲突处理等基线，不预先实现后续同步能力。

## 目标与执行顺序

1. 后端中文注释：82 个手写 Go 文件（含 26 个测试文件）的文件职责、导出方法/主要私有方法和关键约束，1 个自动生成文件不手改。只改注释与必要格式。
2. 115 Cookie SDK：统一可注入请求、账号限速/共享冷却、有限可取消重试、错误分类、快速枚举与标准降级；同步调整抽样预览。
3. 媒体库附属同步：复用正式清单，按 NFO/图片开关下载网盘已有文件，安全发布并报告分类结果。

## 已确认抽样预览

- 最多 3 个不同目录（含根），5 次实际目录请求（含重试），15 秒，20 条文件样例；每页最多 200 条，先触及任一上限即停止。
- 预览不调用整树快速枚举，不下载 NFO/图片，不写产物；只展示“抽样发现”的数量和样例，不推算全库数量。
- 确认执行后才完整扫描；少量抽样目录可能被再次读取，不承诺零重复请求。
- 空样本不代表全库为空，不因抽样未覆盖全库或候选为零阻止合法提交。根目录/授权仍须验证。
- 同步更新 OpenAPI、生成类型、运行时解码和前端提示；关闭自动反复抽样，显式刷新可重读，离开页面取消。

## 已确认附属规则

- NFO 开启：下载配置范围内所有 .nfo。图片开启：下载 .jpg/.jpeg/.png/.gif/.webp/.bmp，大小写不敏感。
- 必须先有同目录视频对应的有效 STRM：本轮成功生成，或已存在且核验为当前库/账号的同源有效产物。无视频、STRM 全失败/冲突/缺失的目录不下载，父子目录不互相替代。
- 满足上述前提后，图片不按 poster/cover/fanart 命名筛选。保持源目录、原名和原始字节，不转码或改写 NFO。
- 本地同名普通文件一律跳过，取链前检查；最终发布仍不可覆盖，防止检查后的竞态。异常目标报告安全冲突。
- 目录枚举只有正式扫描的一轮，不为附件再扫全库；关闭相应开关不下载，也不删除已有文件。

## 关键技术决定

- API 默认读间隔至少 1 秒，允许调大；直链解析与目录读取共享账号配额，尊重 Retry-After，取消/预算不足不继续重试或换端点重扫。
- 实际附属内容下载按账号共享最多 2 个并发，独立于 API 短请求锁；技术初始上限为 NFO 8 MiB、图片 64 MiB，每文件处理总预算 120 秒，内容单次最多 30 秒/最多 3 次。限流者共享冷却，非固定带宽限制。
- 附属采用流式暂存、独立下载意图、完整后不可覆盖原子发布；意图需新增迁移，SQLite/文件间中断按保守 skip 规则恢复。STRM 专用登记及校验不被泛化破坏。
- 任务通用处理数量包含所有条目；STRM/NFO/图片分类成功/跳过/失败在终态日志中明确，不把附件计入 STRM 注册数量。
- 保持单账号 Cookie、公共目录分页 1–200、存量播放 URL/凭证、STRM 所有权/恢复、播放器 UA 及可信 302 目标校验。

## 不包含

## 验收

- 注释覆盖和内容评审；去注释 AST/工具指令不变，格式/vet 等适用门禁。
- SDK 限速、公平性、取消/期限、429/Retry-After、尝试上限、账号切换、脱敏、快慢枚举等价及请求量验证。
- 抽样四项硬边界、零下载、空样本提示、明确刷新/取消、合法确认及完整任务导航。
- 附属开关/后缀、先 STRM 后下载、无视频/STRM 不可用目录零请求、父子目录资格不继承、已有附件零请求、发布竞态、长度/大小错误、迁移与中断恢复、跨任务下载上限及分类统计。
- STRM 生成/恢复/302 的回归，前后端适用门禁、生成一致性、生产构建/冒烟；模拟与真实网盘验证分别记录，环境缺项如实报告。

## 风险与回退

非公开快速接口可能变化，保留受控标准降级和关闭开关，不承诺免限流或固定实盘速度。抽样有偏，可能仅覆盖大根目录的一部分。附属本地已有文件不会自动跟随远端更新；关闭内容开关停止后续下载且保留正式文件。预览新字段需前后端联合发布；下载意图迁移回退受未完成意图保护。

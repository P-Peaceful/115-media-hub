# 媒体库附属文件同步

## 目标与授权

在现有媒体库全量同步中，按配置下载网盘已有 NFO、海报封面等附属文件，保留与源视频相同的相对目录结构。用户已于 2026-11-25 明确要求“开始所有任务”，批准本任务按依赖顺序实现。

## 已确认背景

- GenerateNFO、GeneratePosterCover 已保存和展示，但 STRM 扫描仅收视频，生成器没有附属下载分支。
- `.nfo` 当前不是独立 FileType；附属筛选必须按扩展名/规则，不能只依赖 FileType=document。
- strm_existing_file_policy 的现有合同只覆盖 STRM，不能未经决定自动用于 NFO/图片。
- 现有产物表和写入意图是 STRM 专用，含播放 URL/凭证；路径校验及叶文件读写也含 .strm 与 16 KiB 限制，不可原样承载图片。
- 证据详见 `../11-25-backend-comments-provider115/research/sidecar-sync-gap.md` 及本任务 `research/integration-boundaries.md`。

## 已确认范围与要求

- A-R1：仅当同一源目录中有视频，且至少一个对应 STRM 已成功生成或确认为当前媒体库/账号的同源有效文件后，才允许该目录的附属下载。GenerateNFO 控制网盘已有 .nfo，GeneratePosterCover 控制该目录全部常见图片，不按 poster/cover/fanart 命名筛选。图片集合为 .jpg/.jpeg/.png/.gif/.webp/.bmp，大小写不敏感。关闭相应开关不下载，也不删除本地已有文件。
- A-R2：复用同一轮正式扫描的数据，收集视频与附属文件，不为附件再进行全库遍历。遵守递归、排除、账号和媒体库配置快照。
- A-R3：保留原文件名、相对目录和原始内容字节，NFO 不在同步时擅自改写编码/内容，图片不转码。
- A-R4：抽样预览只展示/检查，不下载文件，不扩大已确认的 3 目录、5 请求、15 秒、20 样例预算。确认后的完整任务才写入。
- A-R5：下载取链走改造后的 Cookie 请求底层；下载可取消、限时限量且并发有界，遵守上游要求的 UA/请求头和可信目标规则，日志不含签名 URL 或凭据。
- A-R6：发布完整文件前不暴露半文件；明确任务取消、网络截断、账号替换、磁盘失败、重跑及本地文件冲突的处理。网络/文件 I/O 不进入数据库事务。
- A-R7：任务结果可区分 STRM 写入和附属下载，提供成功/跳过/失败的实际统计及安全失败原因；单个附属失败不把已经成功的 STRM 当作失败重写。
- A-R8：所有新增/改动 Go 文件保持中文职责和主要方法注释，保留已有 STRM 产物/播放兼容性。
- A-R9：用户已确认本地同名附属文件一律跳过，不跟随 STRM overwrite 配置覆盖。下载前先检查目标，已有普通文件不发取链/下载请求；发布时再次排他检查，处理检查后出现同名文件的竞态。目录、符号链接等异常目标不跟随或改写，按安全冲突报告。
- A-R10：取链 API 与目录等读取共用账号限速和冷却；实际内容下载使用独立的有界并发与响应限流处理，不能因取链已限速就无界启动 CDN 下载，也不能让整个文件传输长期占用账号 API 锁。
- A-R11：先完成 STRM 处理，再按实际结果确定附属下载资格，不能仅凭扫描发现视频或存在未验证 .strm 文件放行。资格按相同源目录 ID 判断，不由父目录/子目录的视频替代；无视频、STRM 全部失败/冲突/缺失/不可信的目录零取链与零下载。重跑和意图恢复同样遵守该前置条件。

## 验收标准

- A-AC1（A-R1、A-R2、A-R11）：覆盖开关、后缀/大小写、非海报名、目录层级与排除；无视频、仅子目录有视频、STRM 全部失败/冲突、缺失或未托管 STRM 时零附属请求；新建成功和已验证同源 STRM 均可放行。快慢扫描资格一致，不增加第二次目录遍历。
- A-AC2（A-R3、A-R5）：下载字节与模拟源一致，保持原名/目录，响应长度、时限、并发、UA 和取消按合同生效。
- A-AC3（A-R4）：预览零下载/零本地写入，既有抽样预算和合法确认行为不回退。
- A-AC4（A-R6、A-R9）：覆盖路径穿越/符号链接、输出重叠、已有文件、检查后出现同名文件、下载截断/超时、账号切换、取消和重跑；已有普通文件零取链/下载、内容不变，竞态也不覆盖；无半文件被当作成功。
- A-AC5（A-R7、A-R8）：任务计数与条目结果一致，日志聚合/脱敏及中文注释检查通过，STRM 生成/恢复/302 的回归通过。
- A-AC6：持久化写入意图和恢复的真实 SQLite 测试覆盖首次迁移、从前版升级、并发目标保留、发布前/后中断和安全回滚；不将附属文件伪装成带播放凭证的 STRM 登记。
- A-AC7（A-R5、A-R10）：模拟验证取链共享账号间隔、内容下载的并发上限和 API/下载锁分离；内容响应 429/Retry-After 触发相应冷却，取消和重试上限生效，不对每个下载独立无界重试。

## 不包含

从 TMDB/Metatube 刮削补齐缺失内容、生成或转换图片、反向上传、删除远端/本地正式文件、自动重命名媒体内容、字幕同步、新的后缀/覆盖设置页面。同步范围以现有两个开关和已确认文件集合为准。

## 依赖与顺序

位于注释、SDK 两个子任务之后；由本任务拥有附属筛选、下载接入、落盘/恢复与任务统计的实际实现。底层传输/节流遵循 SDK 已有设计，必要的新下载方法在本任务中随真实消费者实现，不让两个任务同时改相同文件。父任务负责跨三项验收。

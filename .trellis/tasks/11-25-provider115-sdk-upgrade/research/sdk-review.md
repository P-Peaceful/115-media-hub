## 已定位并修复

1. **业务限流的并发窗口**：原先在 Do 返回、账号 gate 已释放后才登记 HTTP 200 业务限流。新增内部 Request.Inspect，在响应有界读取并关闭后、账号资格仍持有时识别业务错误。随后才做凭据采用检查；旧凭据结果被丢弃时仍保留同账号冷却。受控错误外壳统一 operation 并保留原有 cause，业务限流重试共用总期限及实际发送预算。虚拟时间回归覆盖延迟检查超过普通间隔、排队请求不可越过冷却、旧凭据和预算。
2. **正文网络故障误降级**：读取截断或关闭 I/O 失败原归 Protocol，快速路径会据此切换标准扫描。现归 Temporary，最多三次只读尝试，最终不做快速到标准重扫。超大响应仍为 Protocol；明确 HTTP 401/403/404 在错误正文异常时仍保留授权/缺失分类。补充次数、分类和脱敏回归。
3. **分页与祖先深度边界**：标准单目录新增 10000 次分页调用轮次上限，超限不采用部分目录；测试注入两轮上限而非实际请求一万次。快速目录总深度上限 256 计入缓存前缀，不能通过逐层命中缓存绕过；补充缓存边界回归。
4. **凭据与取消身份**：服务最后一次凭据检查保留 ErrCredentialChanged 和仓储/context cause，阻止子目录请求完成后的窄窗口继续扫描 siblings；Details 对明确 HTTP 授权错误正确返回 invalid，并且可选容量读取的取消不被成功结果吞掉。对应代码由实现代理协同修复，已独立复核实际路径与回归。
5. **快速与标准名字规则**：快速协议校验对齐 UTF-8、255 字节及控制字符约束，坏目录名在采用快照前触发受控标准回退，避免投影阶段整体失败；测试覆盖控制字符与长目录名。
6. **日志真实分类与字段**：provider 操作日志区分取消、期限、授权、限流和凭据变化，取消使用 DEBUG，成功目录页继续 DEBUG。adapter 使用 component=adapter，保留注入 logger 的唯一 module 字段，避免重复 JSON key。日志回归检查稳定类别、错误不外泄及 module 不重复。
7. **确认提示**：修正正式执行仍称“刷新抽样”的残留文案，明确确认后完整扫描。前端保持空样本、抽样未完整时仍可按当前配置与可用输出确认；不会把样本当全库总量。
8. **集成命令透传**：按主代理批准，为 `scripts/test-integration.py` 增加可选正整数 `--workers`、`--timeout-ms`，显式追加 Playwright 对应参数；未提供时默认命令不变。用于受限环境串行冷启动验证，没有改断言、测试范围或产品代码。Python compile、`--help`、diff-check 通过；不为低影响 CLI 透传新增脚本单测。
9. **长间隔与预算兼容**：合法 60 秒间隔大于旧的 45 秒操作预算，导致后台第二页永远不能准入。主代理批准后台只读预算改为 `max(45s, interval + 15s)`；前台 45 秒、播放 15 秒、抽样 15 秒及更早调用方期限保持不变，不缩短冷却。虚拟时间验证两后台页间隔 60 秒成功、第三页受调用方 15 秒期限阻止。Details 的可选容量请求自有预算超时仍保留有效账号资料；只有调用方取消/期限或凭据变更导致整体错误，另有 60 秒间隔回归。

## 主要合同核对

- 同账号单在途、响应完成后间隔 1–60 秒、共享 Retry-After、前台连续四次后的后台机会、取消清队列、总/单次期限和最多三次尝试均保留。扫码不争抢文件队列，登录交换不自动重试。
- 公共 Files 仍最多 200；内部标准 1150 和快速文件/目录 1150/5000 独立有界。快速结果核对根锚点、完整路径、真实元数据 pickcode、分页计数、重复 ID、断链/环与结束凭据。1151 文件、5001 目录分页成功用例及快慢同树候选/排除一致性通过。授权、限流、取消、凭据/仓储错误及暂时传输故障不触发标准重扫。
- 预览仅标准 BFS，3 个不同目录含根、5 次实际发送含重试、15 秒、200 条/页、20 样例，达到边界停止。根未验证不返回空样本成功；页面校验后才采用样例，不创建目录/文件或登记。scan_complete、六种 stop_reason 和 sample 模式沿 OpenAPI→生成类型→运行时解码→展示一致。
- 查询独立 key、静态 stale 策略、无自动重试/焦点/重连/轮询重扫，显式刷新有效，离开取消；正式任务仍重新完整扫描。STRM 内容/所有权/写入恢复与播放器 UA、m115 编解码、可信 115 目标没有放宽。
- 新增/改动的手写 Go 文件与主要方法保持中文职责说明，生成文件来自共享 schema，未手改生成输出。相应 backend/frontend specs 已由主代理同步。

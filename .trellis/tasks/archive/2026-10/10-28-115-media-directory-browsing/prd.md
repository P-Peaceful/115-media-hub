# 115 媒体目录浏览

## Goal

在管理工作台中真实浏览已连接的 115 网盘目录，便于管理员定位媒体文件。前端严格参考用户提供的「单目录」设计图；按需加载单页，不采用「部分加载」设计。后端要求可读、可维护、日志完整且不泄密，并为必要的复杂逻辑写中文注释。

## Background

- 当前已有管理员认证、115 QR 连接和受保护工作台；尚无网盘浏览页面或浏览 API。
- 后端 115 驱动锁定 `github.com/SheltonZhu/115driver v1.3.5`。目录列表响应包含分页总数；`ListPage` 封装会丢弃该总数，`ListWithLimit` 会遍历全目录。实施时应在 adapter 边界保留单页数据与总数，不能为分页而读完整目录。`Stat` 可提供目录文件数/文件夹数和父目录链。
- 前端使用 React Router、TanStack Query、共享 API 客户端；目录和分页等可分享状态应进入 URL。
- 用户提供两张 1440×1024 设计图。本次只采用「单目录」图作为视觉参考；用户明确要求舍弃「部分加载」图及其设计。
- 用户明确决定「创建媒体库」与「加入生成范围」不在本次端到端实现范围；不得呈现虚假成功。

## Requirements

- 提供管理员认证保护的目录浏览页面，支持进入目录、面包屑/返回上级、当前目录搜索、文件类型筛选、服务端分页、刷新和当前页选择。
- 页面数据来自当前配置的 115 连接；目录条目使用稳定 ID，显示名称、大小、修改时间、文件类型及关联状态。
- 每次只按需请求当前页面。加载、后台刷新、成功空目录、当前页失败需分别呈现；失败可重试当前页并保留已缓存内容。没有多页并发预取、部分加载横幅或“失败页等待重试”状态。
- 搜索限于当前目录所有分页，不递归搜索子目录；类型筛选与搜索使用后端可承载的参数，不在浏览器下载完整目录后过滤。
- 搜索/筛选/目录/页码等可分享的状态由 URL 表达；变更目录或搜索条件重置页码和临时选择，旧响应不得覆盖新目录结果。
- 「创建媒体库」与「加入生成范围」入口在单目录布局中保留，但不实现其端到端业务，也不产生虚假成功；以明确不可用/尚未接入状态呈现。
- 后端沿 OpenAPI → 生成代码 → HTTP handler → service → 115 adapter 分层。日志能识别操作、耗时及安全的结果/错误分类，不记录凭证、搜索词、目录名、原始敏感响应或不必要的路径信息；必要处添加中文注释。

## Acceptance Criteria

- AC1：可从工作台网盘浏览入口进入根目录；已连接时显示真实的 115 当前目录条目及分页总数，进入目录后目录名和父级面包屑正确；媒体库关联按本次未接入状态呈现，不伪造关联数据。
- AC2：进入文件夹、返回上级/面包屑、搜索、类型筛选、刷新、分页和当前页选择工作正常；刷新、前进后退可恢复 URL 表达的目录及查询状态。
- AC3：页面仅请求当前页；目录列表使用 SDK 分页响应中的总数，不扫描全目录取总数；未认证被拒绝，未配置连接、无效目录和上游错误明确呈现。
- AC4：当前页失败时不清除已显示/缓存内容，显示可理解的错误并只重试当前查询页；加载、空结果与失败状态可区分；不显示部分加载页面的提示或多页失败提示。
- AC5：单目录页面的布局、信息层级、颜色、间距、中文文案及操作位置与图 05 对照实现；关键控件键盘可用，图标控件有可访问名称。
- AC6：日志能定位浏览请求、结果类别和耗时，无搜索词、文件名、凭证、cookie、完整原始错误载荷等敏感内容。
- AC7：OpenAPI 与生成产物一致；代码路径包含 adapter/service/API/UI 所需行为；项目配置的静态检查和构建通过。

## Out of Scope

- 图 06 的部分加载状态、前三页预取、并行多页加载和部分页重试。
- 「创建媒体库」与「加入生成范围」的端到端工作流，媒体库/扫描/STRM/任务业务。
- 115 云端文件删除、移动、重命名、上传等写操作，以及递归展开目录。

## Decisions

- 读取策略：用户选择按需加载单页；进入目录时只请求当前页，不为预演失败状态请求其他页。
- UI 参考：图 05 单目录；图 06 明确不作为需求。
- 目录操作入口：保留单目录图中的位置，但不接入实际后端业务或假成功。

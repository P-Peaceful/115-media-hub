# 后端变更边界

当前基础仅提供公开健康检查和 SPA。缺少的行为应由职责内聚的认证服务、SQLite 仓储、HTTP 中间件/处理器及本地密码恢复入口共同实现。本实现负责 `backend/**`、`api/openapi.yaml` 和生成的前端 schema；主代理负责部署文档/构建脚本/规范；前端实现代理负责其他前端文件。不增加服务商集成、设置编辑器或业务仪表盘。

先定义契约，再重新生成两端产物。新增不可逆凭据迁移并保留现有应用结构。服务策略不依赖 Gin/GORM；仓储事务原子地包含必需审计；传输层负责有界 JSON、Cookie、Origin 和 CSRF。尽可能保留现有路由/readiness 和生命周期接口。新模块使用受支持的 Go/Gin/GORM/bcrypt API；密码/会话/CSRF 密钥不得进入日志或审计。使用真实 SQLite、服务时钟和 HTTP 测试验证变更边界。

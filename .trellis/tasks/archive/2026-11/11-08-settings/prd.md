# 设置模块：管理员与安全、115 账号

## 目标和背景

提供可访问的设置页面，让个人用户管理管理员安全设置并通过 115 App 扫码配置唯一的 115 账号。`reference.png` 仅是中间模块内容区域的视觉参考；左侧菜单栏和顶部面包屑保持项目现有全局布局。115 账号页面的细节由项目现有样式与本需求决定。桌面共享侧栏以视口为基准，不随中间内容高度变化，不设置独立滚动条并保证菜单可见；顶部面包屑在页面滚动条出现或消失时宽度保持稳定。

现有侧栏设置入口不可用；系统已有单管理员、初始化、登录、登出及固定期限的会话。初始化已保存 1/7/30 天登录有效期；登录页的“记住登录状态”决定持久 Cookie 或浏览器会话 Cookie。服务端固定到期时间始终适用。

## 需求

1. 开放设置入口，提供“管理员与安全”和“115 账号”两个可用分类，高度还原参考图，优先使用 HeroUI 组件；适配桌面和窄屏、亮暗主题与键盘操作。其余截图分类不属于本次交付。
2. 支持修改管理员用户名和密码，遵循现有用户名与密码校验规则；修改时验证当前密码，新密码须确认。成功后撤销其他管理员会话，保留当前会话；失败不得产生部分更改。提供明确的提交、成功和错误反馈。
3. 可查看和修改 1、7、30 天的登录有效期，持久化设置供后续登录使用；已创建会话保持原有到期时间。保留登录页现有“记住登录状态”用法，不增加全局强制开关。提供退出当前会话，沿用现有登出和缓存清理行为。
4. 仅支持一个 115 账号，使用 115 App 扫码登录。展示未配置、等待扫码、已扫码待确认、成功、过期、取消及失败状态，并可重新获取二维码。成功后展示可用的非敏感账号信息；允许重新扫码和移除本地授权。扫码成功直接更新唯一授权，不比较账号身份、不增加换号确认；失败或取消不覆盖现有授权。
5. 115 账号页面展示上游可用的真实账号与容量信息，包括头像、是否为会员、会员到期/永久状态和登录设备列表；遵循 Cookie 网页接口实际返回及参考项目验证过的字段映射，不展示原始会员等级整数。总览“115 连接状态”“网盘容量”和左侧底部授权卡按照 `dashboard-reference.png` 的布局与视觉层级实现，展示真实状态、最近检测时间、已用/总量/剩余量及进度百分比；总览和共享侧栏卡片不得填充截图中的示例账号或数字。Cookie 授权没有固定期限时不推算“剩余天数”。未授权、失效及上游错误应准确区分。提供主动检查授权状态的操作，准确区分有效、失效和无法确认。菜单链接去掉下划线。
6. 115 接口可参考 115-station 的地址和流程，但由本项目实现，不依赖第三方 115 SDK。上游不可用时报告真实错误，不把失败伪装为成功。用户明确要求不对 115 凭据加密保存，也不要求配置主密钥；凭据由服务端保存。管理操作沿用现有管理员认证与 CSRF 保护。前后端代码保持可读，后端业务流程记录结构化日志，供后续日志模块使用。

## 验收标准

- [x] 已登录管理员能从侧栏打开两个设置分类；未登录用户不能读写受保护设置。
- [x] 正确的当前密码允许修改用户名和/或密码，新凭据可用于登录；错误当前密码、非法输入及确认不一致不会更改凭据。成功后当前会话仍有效，其他旧会话失效。
- [x] 修改登录有效期后刷新和重启仍保留，后续会话采用新期限，已有会话期限不变；登录页记住登录行为不变，退出当前会话后受保护页面和缓存按现有规则清理。
- [x] 通过可控的上游模拟覆盖扫码等待、确认、成功、失效、取消、网络及上游错误；成功后授权跨重启保留，失败或取消不覆盖原授权；移除后本地不再持有该授权。
- [x] 无需配置主密钥即可保存和恢复 115 授权；数据库可直接保存凭据，重新授权失败不得覆盖已有授权。
- [x] 账号页能显示可用的头像、会员状态与到期/永久状态、登录设备列表及容量；手动检查通过实时 Cookie 请求确认授权有效或失效，网络/上游错误显示无法确认。
- [x] 关键交互在桌面、窄屏、亮暗主题和键盘下可用；真实 115 扫码验证结果与模拟测试分别报告。

## 不在范围

其他设置分类、115 多账号、手动 Cookie 导入、开放平台 OAuth、网盘浏览、媒体库及相关业务。单账号换号的业务影响由个人用户自行处理。

## 参考和限制

- [115-station 扫码实现](https://github.com/pancras-loe/115-station/blob/c5d308beff82448c7d223b51edae37053fe88ff5/internal/api/115.go) 作为接口参考；详见 `research/115-qr.md`。上游接口可能改变，模拟测试不能证明真实环境始终可用。
- 用户明确决定本任务不遵循项目基线中外部凭据加密和独立主密钥的要求；数据库备份包含可直接使用的 115 凭据。修改认证及设置仍需遵循现有认证、审计和 OpenAPI 规范。

# 网盘浏览模块

## 目标与背景

根据[设计图](design-reference.png)实现真实 115 网盘的桌面端目录浏览，让用户通过已授权账号查找文件并查看详情。截图中的文件名、容量和关联状态仅为视觉示例。

项目已有单账号扫码授权、账号与容量展示；网盘浏览导航目前不可用，尚无目录浏览接口或页面，媒体库业务也尚未实现。

## 需求

1. 接入当前授权的真实 115 网盘，展示根目录和子目录；支持进入目录、面包屑返回、返回上级及刷新，正确处理大型目录。
2. 按设计图复用应用布局，展示名称、媒体库关联状态、大小、修改时间、文件类型和行操作；提供当前目录内搜索（若不能可靠实现则暂缓，并标示不可用）、名称/大小/时间排序、文件类型筛选及列表/网格视图切换。已实现的搜索、排序和筛选应覆盖当前目录的完整结果，而非仅已加载页面。
3. 行操作仅提供查看详情和复制路径；文件详情侧栏展示完整路径、大小、类型、修改时间及所属媒体库，并支持复制路径和关闭侧栏。复制路径以 `/` 开头，不包含根节点显示标签，分隔符两侧不添加空格，目录与文件名原有空格保持不变。上游无可靠值时明确显示不可用，不编造数据。
4. 媒体库关联状态显示“暂不可用”，跳转媒体库按钮禁用；不虚构未关联或实际关联状态。
5. 提供加载、空目录、无搜索结果、未授权、授权失效和请求失败状态，以及适当的重试或授权入口；网络错误不冒充授权失效。保留键盘可操作性及现有主题适配。

## 验收标准

- [ ] 已授权账号可浏览真实根目录和多级目录，面包屑、返回上级及刷新反映实际目录；无截图示例数据。
- [ ] 大目录可完整浏览，排序及类型筛选对完整当前目录生效；如搜索不能可靠实现则禁用并标明暂不可用；切换列表和网格后结果一致。
- [ ] 查看详情与复制路径可用，文件信息对应所选真实条目；无法获得的信息明确标示。
- [ ] 媒体库状态为“暂不可用”，跳转按钮禁用；菜单不提供删除、移动或重命名。
- [ ] 加载、空、无匹配、未授权、授权失效、上游失败等状态可区分，失败可恢复。
- [ ] 界面与设计图的两个桌面状态保持主要结构和视觉层级一致，并支持键盘和现有主题。
- [ ] 自动化检查覆盖真实数据流的关键路径、分页和错误状态；实际 115 联调结果单独说明。

## 范围外

媒体库管理及真实关联、扫描、网盘写操作（包括删除、移动和重命名）、多账号管理。设计图外的独立业务模块不在本任务内。

## 技术约束

沿用现有单账号 Cookie 授权与管理员会话，不将凭据暴露给浏览器；共享 API 以 `api/openapi.yaml` 为准，目录和文件标识使用字符串，大列表分页。115 上游目录接口及搜索、排序、筛选能力须在实现前验证；如上游不能支撑完整目录语义，应调整实现方案或返回规划确认，不能静默退化为当前页结果。

## 实施要求

用户批准上述规划；前端优先使用当前版本 HeroUI 组件和有效 API，高保真还原设计图；前后端代码应清晰可读，只添加验证必要行为的测试。

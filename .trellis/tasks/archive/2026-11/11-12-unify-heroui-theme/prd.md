# 统一项目主题与 HeroUI 组件

## 目标

以用户提供的 HeroUI 主题统一前端，并按指定设计图更新总览、侧栏、面包屑、媒体库和网盘浏览体验；保留真实数据、现有业务行为和亮暗/响应式支持。

## 背景与需求

- 用户指定的 HeroUI Theme Builder 配置已导出至 `frontend/src/styles/globals.css`，是主题颜色与圆角的权威来源。
- 可由 HeroUI v3 提供的控件使用对应组件及公开 API；组件外观优先使用库样式，应用布局与自有视觉元素可使用主题语义变量。
- 侧栏、面包屑和总览卡片按用户提供的设计参考实现，颜色适配当前亮暗主题。
- 媒体库卡片展示类型图标、标题、类型、真实启停状态和现有目录数据。没有接口支持的 STRM 数量及同步时间不得伪造。
- 网盘浏览区使用单一 Card、Breadcrumbs、Table、Table.Footer 内 Pagination 和 Modal 详情。保留目录历史、过滤、排序、操作、游标兼容和键盘焦点行为。
- 将 115 上游目录总数透传至前端，并提供上一页、页码及下一页分页；切换目录、排序或过滤后回到第一页，支持浏览器历史导航。
- 新建媒体库时，未选择必填 115 目录应阻止提交并显示可访问的字段错误；选择后清除错误，编辑行为保持可用。
- 总览、网盘、媒体库、设置及应用外壳在亮暗模式和窄屏下布局可用。

## 验收标准

- [x] 用户提供的主题覆盖应用页面与浮层，亮暗主题切换正常。
- [x] 侧栏及面包屑使用主题语义色；总览版式、状态与卡片层级按设计参考调整。
- [x] 媒体库卡片按类型呈现图标、状态徽标和目录信息，并保留真实状态与操作。
- [x] 网盘浏览区使用 HeroUI Card、Breadcrumbs、Table、Footer/Pagination、Modal；详情不会挤压表格。
- [x] 网盘总数透传并呈现完整的上一页、页码、下一页分页；筛选、排序、目录切换和浏览器历史正确更新页码。
- [x] 进入目录时面包屑平稳更新，慢请求、失败、迟到响应及历史导航不会把旧路径误作当前路径。
- [x] 媒体库新建表单的目录必填校验在字段旁可见且可访问；选择后能清除并成功提交。
- [x] 前端格式、lint、类型、单测、构建及相关桌面/窄屏浏览器检查通过；后端测试、race、vet、lint及生成契约检查通过。

## 限制

- 尚未通过真实 115 服务验证文件类型过滤条件下 `count` 的语义；显示总数依赖现有上游契约。
- 115 使用偏移分页，目录实时变化可能导致页内容移动。
- 用户给出的示例数据与未实现功能不作为真实数据或可用操作呈现。

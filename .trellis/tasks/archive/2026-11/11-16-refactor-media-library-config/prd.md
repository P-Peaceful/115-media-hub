# 重构媒体库配置

## Goal

让新建和编辑媒体库按用户提供的设计图重构，使配置分组直观，并支持保存和重新编辑媒体库及 STRM 设置。

## Background

- 新建和编辑共用 `frontend/src/features/media-library/library-page.tsx` 中的表单。
- 媒体库 API 通过 OpenAPI 定义配置字段；后端将配置序列化到 `media_libraries.config_json`。增添字段需要扩展 OpenAPI、前后端类型、服务端校验和前端往返回显。
- 设计图是交互和视觉参考。用户明确补充的移除/新增要求优先于图中内容。

## Requirements

### 基本信息

- 提供媒体库名称、媒体类型、语言偏好和刮削源设置；默认值为电影、简体中文和 TMDB。语言偏好本期仅提供简体中文；刮削源选项为 TMDB、MetaTube、不刮削。

### 目录绑定

- 提供媒体库网盘目录和排除目录配置，以及包含子目录、跟随网盘目录变更开关。
- 新建与编辑均可保存并回显这些设置。

### 输出设置

- 提供本地输出目录、生成 STRM 文件、NFO 信息、海报与封面以及文件编码设置；参考图中的编码默认值为 UTF-8（推荐）。
- 不显示目录结构设置。
- 在生成内容下方新增“STRM 已存在时”，选项“跳过（默认）/覆盖”，以目标输出路径下同名 STRM 文件为判定依据。关闭生成 STRM 时禁用该选项，保留其选择值；新建/编辑可保存并回显。本期只保存偏好，不执行文件覆盖。

### STRM 链接配置

- 提供链接类型、STRM 直连域名和链接格式。
- 链接类型新建默认选择“302 代理”。
- 链接格式使用 Tab，选项为“文件原名”和“文件 ID”。
- 修正链接格式标签与 Tab 的垂直对齐；下方新增随格式及域名输入变化的链接示例，窄屏长链接可换行。示例仅用于展示，不宣称存在可播放接口。
- 不显示链接参数及“生成多清晰度 STRM”。

### 全局移除项

- 移除文件规则卡片。
- 不提供自动清理功能。

### 删除确认弹窗优化（2026-11-19）

- 用户要求使用 HeroUI `AlertDialog` 替换当前删除确认 Modal，使用组件的标题、警示图标、正文与底部操作结构改善排版。
- 保留“只删除配置，网盘及本地文件不会被删除”的明确说明，长名称可换行；取消/确认有清晰层次，适配亮暗主题和窄屏。
- 删除提交中防重复提交和关闭，错误留在弹窗允许重试；成功后关闭。保留键盘访问、标题/描述语义、取消与关闭后的焦点恢复。

### 通用行为

- 表单仅展示设计图中的字段及本需求明确新增的字段；不提供描述、路径映射、目录结构、文件规则或链接有效期配置。启用状态继续由现有独立启停操作管理。
- 新建与编辑共享同一套配置表单；成功保存后编辑能回显配置。
- 不要求兼容旧版媒体库配置，不做旧配置字段映射、默认值回填或旧数据迁移。
- 2026-11-19 加载故障修正：仅对本轮新增 `strm_existing_file_policy` 缺失的已保存记录按 `skip` 读取；不将明确的非法值默认为 skip，不扩大到其他旧配置字段。已有媒体库必须能继续加载，新请求仍必须提供合法策略。
- 配置仅保存设置；扫描、自动清理、STRM/NFO/海报实际生成继续遵循既有后续功能边界，不因增加配置字段而宣称已执行。

## Acceptance Criteria

- 新建和编辑表单按设计图形成“基本信息、目录绑定、输出设置、STRM 链接配置”卡片布局，并在窄屏下保持可读和可操作。
- 基本信息、目录绑定、输出设置和 STRM 卡片展示本需求列出的字段；明确移除项均不出现。
- 语言偏好仅有“简体中文”；新建默认刮削源为 TMDB，且可切换为 MetaTube 或不刮削。
- 链接类型新建默认值为“302 代理”，链接格式 Tab 可在两项间切换。
- 新配置可通过创建/更新 API 持久化，并在编辑页重新读取时一致；不对旧版配置保证读取或回填。
- 前后端请求验证、OpenAPI 生成类型和错误处理保持一致；现有鉴权、CSRF、revision 行为不回退。

## Out of Scope

- 扫描目录、网盘变更监听、媒体刮削、STRM/NFO/海报生成、链接实际解析和自动清理的运行时行为。
- 旧媒体库配置的兼容、迁移与数据回填。

## 详情页改版（2026-11-18 补充）

- 用户明确要求将详情页改版并入本任务，以本轮提供的设计图作为视觉参考。
- 对齐顶部横幅、四个操作入口、库概览、当前状态、绑定目录、输出设置摘要、STRM 统计、最近同步时间和执行记录摘要的布局及视觉层次；适配窄屏及现有主题。
- 现状证据：`frontend/src/features/media-library/library-page.tsx:876` 已有七个分区，但统计和记录仅有简单占位，操作入口及卡片布局与参考图存在差异。
- 数据条件：系统运行时长和构建版本已有接口及 `frontend/src/features/dashboard/system-status.ts`；同步操作、STRM 统计和执行记录尚未实现。配置契约没有参考图中的“保留结构”字段。

### 数据与交互

- 用户确认：没有接口的数据先展示 mock 数据。本次不新增同步执行和统计后端。
- 已有配置、系统运行时长和构建版本使用真实接口；STRM 总数、已生成、待处理、失败、最近同步及执行记录使用固定演示数据，对应区域明确标注“演示数据”。
- 同步和执行预览按钮保持禁用并提供原因；编辑配置使用现有真实路由。目录行可导航至已有网盘浏览入口；不提供不存在的输出目录浏览、执行记录列表或同步操作。
- 当前状态区展示真实系统信息；媒体库启用状态使用“已启用/已暂停”，不将其描述为同步运行中。保留现有独立启停能力。
- 输出摘要使用现有输出目录、文件编码和 NFO 配置，不新增已明确移除的“目录结构”字段。

### 验收补充

- 详情页呈现参考图的紫色横幅、四操作入口、两列概览/状态及目录/输出卡片、宽统计/窄最近同步卡片和通栏记录区；窄屏顺序堆叠且无横向溢出。
- 演示统计展示总数及三个分类，演示记录采用时间线与结果标签；演示标识可见，不能伪装成真实执行结果。
- 真实数据加载失败不以 mock 替代；配置错误、系统信息错误及启停失败保留可理解的反馈。
- 亮暗主题、长名称/路径、键盘操作及原有新建/编辑流程不回退。

# 技术设计

## 入口与布局

在现有认证应用外壳中，将 `/libraries/:id` 作为媒体库详情路由组。索引路由渲染现有详情，三个下级路由各自渲染完整页面。

| 页面 | 路径 |
| --- | --- |
| 执行预览 | `/libraries/:id/full-sync/execution-preview` |
| 全量同步 | `/libraries/:id/full-sync` |
| 增量同步 | `/libraries/:id/incremental-sync` |

详情页的全量同步、增量同步和编辑配置入口统一使用 HeroUI Button，触发后通过 React Router 导航。全量同步和增量同步的返回链接直接指向当前媒体库详情。全量同步的下一步进入执行预览，预览中的返回和取消均回到全量同步。宽屏沿用设计图的横向分区，窄屏堆叠卡片，宽表格在自身容器内滚动。横幅插图在宽屏右侧按原比例完整显示，窄屏隐藏。沿用项目的语义颜色、标题层次和主题。

历史记录和异常详情在所属页面内展开，并提供收起或返回操作。可分享的预览筛选使用 URL 查询参数。展开状态和演示反馈由各页面维护。

## 数据与状态

- 详情视图以只读方式展示全部可编辑配置。编辑入口在浏览器历史记录中标记来源，取消时返回上一条记录，列表筛选由 URL 保留。直接进入编辑时，取消返回列表。
- 详情路由组复用现有媒体库详情查询及缓存键，从 URL 读取媒体库 ID，并在共享布局中处理加载和错误。索引路由和下级页面复用已加载的 `Library`，因此直接访问和刷新时也能正确显示配置。示例变更路径使用当前源路径加样例文件名，运行类信息保持可见的演示标识。
- 演示统计、样例变更、历史和异常集中在媒体库特性内。预计总数和分类数量从同一统计对象派生，明细展示独立的样例子集。
- 运行按钮使用可访问的本地状态反馈。历史样例保持其原有记录语义。
- 监听开关和轮询输入由以媒体库 ID 为边界的详情路由组持有。默认值参考图中的 30 秒和 500 条，控件变化只作用于本地状态。切换 ID、刷新或离开详情路由组后恢复默认值。

## 兼容与回退

改动限于前端路由、媒体库详情及下级页面、演示数据和对应验证。继续使用现有 API 类型，项目无须迁移或升级依赖。如需回退，撤回三个入口及其专用路由和前端模块。

# 实施计划

1. 核对详情路由、认证应用外壳、媒体库详情查询、主题约定和现有测试。读取前端规范并确认锁定版本的组件接口。
2. 建立媒体库详情路由组及三个下级页面，接通详情页和返回链接。复用详情查询，验证直达、刷新、浏览器前进后退和媒体库间的状态隔离。
3. 完成执行预览的同口径统计、分类筛选和反馈。
4. 完成全量同步的范围卡、最近执行、历史展开、记录详情和反馈。
5. 完成增量同步的监听设置、状态统计、触发记录、异常列表及详情交互。
6. 更新现有媒体库详情单测与浏览器用例。覆盖 R1–R4，包括有效和失效媒体库 ID 的直达行为、演示操作的网络副作用验证、窄屏布局以及原有详情操作回归。
7. 在 `frontend/` 运行 `pnpm format:check`、`pnpm lint`、`pnpm typecheck`、`pnpm test:run`、`pnpm build` 和 `pnpm test:e2e e2e/media-library-detail.spec.ts`。在浏览器检查三个下级页面的桌面与窄屏布局、主题和键盘导航。

回退点为媒体库详情的三个入口及其专用前端模块。审查时重点验证样例标识、当前媒体库路径和跨库设置隔离。

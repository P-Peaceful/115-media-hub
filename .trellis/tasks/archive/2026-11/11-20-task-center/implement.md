# 任务中心实施计划

1. 固定七类任务及能力查询、任务状态、计划时区和失败重试的 OpenAPI 契约。明确未接入时的错误码、缺失指标和分页行为。运行 `make generate`。
2. 新增 SQLite 计划、运行、任务项和任务日志的迁移与仓储。覆盖旧库升级、原子领取和同一触发时点去重。
3. 实现只调用已注册模块的 worker、计划触发和重启核验流程。在应用构建和关闭流程中接入调度器。用测试模块覆盖单个及全部媒体库、停用、失败、取消、暂停、按项重试和恢复。核对生产注册结果以及模块缺失时的行为。
4. 实现受认证的查询与单条操作 API、SSE 通知。验证会话、CSRF、稳定错误、持久化结果、脱敏和执行审计。
5. 实现四个页面并接入现有侧栏。保留七类筛选，接入真实空状态和能力限制，移除执行参数与列表批量选择。验证直达、历史导航、筛选和站内结果提示。
6. 运行 `make check`、任务中心相关 Playwright 用例和 `make build smoke`。检查桌面与窄屏、亮暗主题和键盘交互。使用测试执行入口验证计划到点、任务详情、日志和重试的完整链路。
7. 核对最终生产能力清单，记录本期已接入和待业务模块提供的类型。更新正式任务中心契约及相关规范。

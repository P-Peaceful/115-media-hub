# 任务中心开发

## 目标

集中查看媒体处理任务的进度、结果和日志，排查失败并重试，管理按周期自动运行的计划。任务中心负责调度、运行状态和历史记录，各业务模块负责具体的媒体处理。

## 交付范围

- 交付任务总览、任务详情、定时计划列表和计划编辑，以及真实的持久化队列、定时调度和任务管理接口。
- 前端保留扫描、STRM 生成、同步、检查、清理、刮削、回传七类。「全部」用于汇总和筛选。
- 本期后端仅接入已有业务模块提供的可运行能力。仓库基线中的 115 服务提供分页目录浏览，媒体库服务负责保存配置，同步和执行预览为前端演示。当前七类均缺少独立的业务执行入口。上线时按实际注册能力开放操作，尚不可用的类型在分类中可见，计划编辑中标为暂不可用。
- 媒体库是执行配置的唯一来源。手动触发、定时触发和重试使用类型与目标媒体库定位配置。任务详情和计划编辑移除「执行参数」区块。
- 所有列表去掉行复选框、全选框和批量操作。任务和计划操作按单条记录执行。「仅重试失败项」处理当前任务的全部失败项。
- 四个页面中的控件、卡片和反馈组件使用 HeroUI v3 官方组件及其内置样式，接入项目统一的亮色和暗色主题。页面网格、语义内容和插图沿用现有布局。
- 扫描、STRM 生成、同步、检查、清理、刮削、回传的业务实现归各自模块。清理模块接入后按已确认规则自动处理符合条件的本地产物，默认关闭。任务中心显示模块返回的删除、跳过和失败结果。

## 验收标准

| 页面或流程 | 可验收结果 | 设计图 |
| --- | --- | --- |
| 任务总览 | 展示七类的真实计数。状态分组包含运行中、排队中、已暂停、已完成、失败、已取消。按类别、媒体库和状态筛选及刷新。列表按执行器上报的指标展示进度、速度、耗时和当前文件，缺失指标展示空值。尚无任务时显示真实空状态。暂停、恢复和取消按运行状态及模块声明的能力显示。 | [任务总览](references/task-overview.png) |
| 任务详情 | 展示任务来源、媒体库、耗时、进度、结果统计、失败文件与原因和关联日志。支持整任务重试，支持按项重试的模块提供「仅重试失败项」。重试产生关联的独立运行记录。 | [任务详情](references/task-details.png) |
| 定时计划 | 支持创建、编辑、启停和删除已接入类型的计划。按类型、媒体库和启停状态筛选，展示下次执行时间。启用计划到点自动创建任务，停用后停止产生新任务。 | [定时计划](references/schedule-list.png) |
| 计划编辑 | 选择执行类型、单个或全部媒体库、触发周期和结果通知偏好。提供每天、每周、每月和自定义周期。无法执行的类型显示原因，阻止保存为计划。 | [编辑计划](references/schedule-editor.png) |
| 调度闭环 | 用测试专用的业务模块验证到点入队、执行、持久化进度和结果、失败与重试、取消和重启恢复。生产环境按实际接入能力运行，空执行器列表下也可正常浏览页面与接口。 | |

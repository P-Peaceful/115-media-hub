# 实施与验收计划

1. 核验播放解析可行性。选择已授权的测试样本，验证上游临时链接、302 跟随及播放器打开媒体。记录脱敏结果并准备稳定的上游测试替身。
2. 明确媒体库共享播放地址、凭据、管理查询和全量同步任务能力契约，更新 OpenAPI 并用 `make generate` 生成前后端类型。加入可独立升级的产物登记迁移。
3. 实现 115 目录遍历、产物路径校验、写入意图及恢复。用临时目录验证部分失败、重跑、跨库冲突、符号链接、用户修改和写盘失败。
4. 向任务中心注册执行器并实现播放解析。覆盖媒体库资格、任务进度、取消、失败分类、播放器凭据以及日志脱敏。用测试替身验证 302 目标和播放器可以取得媒体内容。
5. 实现真实 STRM 管理读取和媒体库跳转，沿用 HeroUI 和项目主题。验证任务完成后的刷新、按库统计、列表筛选、详情真实内容、空状态及无权限反馈。
6. 运行 `make check`、相关 Playwright 场景以及 `make build smoke`。对一个授权的 115 样本跑完整流程，分开记录真实播放与模拟上游的验证结果。
7. 验证已有 SQLite 数据升级，记录迁移和回退所需的数据库及产物前提。更新受影响的 Trellis 契约。

实施范围已由用户确认。

## 验证结果

- `make check` 通过。包含 140 项前端单测、Go 单测及竞态检查、静态检查和 OpenAPI 再生成校验。
- 全量同步、媒体库配置和详情、STRM 管理、任务中心及页面横幅的专项 Playwright 共 28 项通过，包含桌面浅色与移动端深色。全站检查中其余 14 项失败在主分支上复现。
- `make build smoke` 验证生产资源嵌入、应用启动、会话持久化和路由隔离。
- 后端集成测试使用临时 SQLite、输出目录和模拟上游，覆盖任务提交、生成及重跑、真实产物读取、302 跟随、篡改后预览状态和日志脱敏。
- 使用本地已有 115 授权只读选取实际媒体样本。调用真实适配器的临时 302 服务成功让 FFmpeg 8.1.2 解码首帧。[真实上游验证](research/115-playback.md)
- 执行预览修订后，用当前媒体库和真实 115 授权在隔离实例验收。预览扫描到 48 个视频和 48 个 STRM 候选，未创建缺失的临时输出目录，也未写入任务历史。确认同步后创建目录，任务完成并生成 48 个文件。桌面浅色和移动端深色的 12 项媒体库及 STRM 专项浏览器场景通过。
- 移除本地 STRM 哈希后，`make check`、构建与冒烟测试通过。用实际数据库副本验证从版本 6 升级到 7，6 条产物登记、播放链接和原有文件字节均可读取。测试覆盖不同扩展名映射到同一个输出路径、外部内容变更和中断后的恢复。
- 覆盖写入使用 Linux 原子交换，先保留被替换的文件。若进程在交换后校验前退出，被替换内容可能留在隐藏暂存文件中，供管理员核对。
- 按设计图调整 STRM 列表后，`make check` 和 20 项相关 Playwright 场景通过。使用实际数据库副本在浅色、深色主题验证 7 条登记记录以及从列表进入详情。
- 按设计图复原媒体库详情的统计和执行记录卡片。前端 140 项单测通过，媒体库详情和 STRM 管理的 18 项浏览器场景分批通过。使用实际数据库副本在浅色、深色主题核对 7 条 STRM 登记、最近四条同步任务及页面跳转。

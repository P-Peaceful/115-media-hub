- [x] 同一标准/快速清单保留视频与附件的源目录 ID；先生成/验证 STRM，再仅为具备同目录有效 STRM 的目录安排 .nfo 和所有已选图片，不按海报名过滤。
- [x] 开关、目录排除/递归、账号和完整目录/快照规则共用；无新增全库枚举。
- [x] 保持预览只读、零下载和四项硬预算；预览抽样计数不冒充附件/全库总量。
- [x] 测试全部后缀/大小写、开关组合和快慢等价；无视频/仅子目录视频/STRM 全失败或冲突/仅外部或缺失 STRM 目录零下载，新建或已验证同源 STRM 可下载，且无第二次目录遍历。

## 2. 下载与控制

- [x] 基于 SDK 增加真实消费者所需的下载描述与流式内容传输，不把 STRM 302 当作下载实现。
- [x] 无同目录有效 STRM 的附件先跳过，已有普通附件也在取链前跳过；API 共用账号限速，内容下载全账号最多 2 并发，有界队列。
- [x] 实现 NFO 8 MiB/图片 64 MiB、文件总预算 120 秒、内容单次 30 秒/最多 3 次；处理 Retry-After、共享冷却、有限刷新过期链接与取消。
- [x] 验证 UA/必要头、HTTPS/重定向目标与日志脱敏；覆盖网络截断、超限、错误长度、403/429/5xx 和账号变化。

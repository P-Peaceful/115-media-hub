# 参考 115-station 改造 115 客户端底层能力

## 目标

借鉴 115-station 请求控制与扫描方式，改进自有 115 客户端，使网盘访问与 STRM 扫描具备清晰边界、可控请求频率和可靠错误处理。来源为用户 2026-11-25 第二项需求。

## 已确认背景

- 当前由 backend/internal/service/provider115 自行承担授权编排、传输、目录解析与取链；仅播放协议编解码引用已固定版本 115driver 的 m115 包，并未采用其完整客户端。
- Cookie 列表走 https://webapi.115.com/files；公共分页为 1–200。STRM 使用同接口逐目录串行扫描，预览和执行分别扫描。
- 当前没有主动节流；目录传输缺少限流专项处理，多种错误合并为 ErrUpstream。播放适配器已识别 HTTP 429 等错误，但没有共享的冷却/重试机制。
- 已有账号替换、目录身份、可信播放目标校验及持久化产物凭证/所有权/恢复机制，改造不可削弱。
- 上游参考固定为 d4251d0083bf344b38569da7bbb4def1893b6401（2026-11-24）。详见 research/provider115-baseline.md。

## 已确认要求

- S-R1：参考流程和接口，自行实现；不复制上游实现，不引入其路由层耦合和包级全局状态。
- S-R2：维护现有 Cookie 数据兼容性及认证、身份、分页完整性、账号切换、STRM 安全边界。
- S-R3：网络和等待服从 context 取消与期限；限制资源，不在数据库事务执行外部 I/O。
- S-R4：新代码具备中文文件职责和主要方法注释。
- S-R5：区分授权失败、限流、暂时故障与协议异常；不记录 Cookie、pickcode、签名 URL 和原始敏感响应。

## 已确认范围

用户已选择方案 A：聚焦现有 Cookie 通道。

- S-R6：统一可注入传输、超时、响应边界及上游错误分类；接入现有账号读取、目录浏览、播放及扫码请求。
- S-R7：按账号统一节流，默认读请求最小间隔 1 秒，支持配置更长间隔；限流时共享冷却，重试有次数与时限约束且可取消，播放不排在整个扫描任务之后。
- S-R8：支持快速扫描（递归文件列表 + 目录表 + 内存路径重建）、较大内部标准批次与受控降级。非递归配置仍只读取当前目录，公共浏览分页维持 1–200。
- S-R9：预览只做有预算的少量目录抽样，保留文件样例；确认后由正式任务完成完整扫描。不缓存复用预览结果，不在确认前进行全库扫描。抽样数量必须明确标注，不得当作全库总量或完成目录的完整统计。
- S-R10：快速扫描使用本项目真实目录 pickcode 获取与严格身份校验，不要求照搬上游本地换算实现；能力不支持或清单无法确认完整时受控回退标准扫描。
- S-R11：用户已确认抽样上限：3 个不同目录、5 次上游目录请求（含重试）、15 秒、20 条返回样例，先触及任一上限即停止。根目录计入目录数，每页最多 200 条。请求预算必须在实际发送边界执行。

## 不包含

OpenAPI OAuth、生活事件增量、多账号、分享/回收站、网盘写操作、自动整理/刮削、新的配置管理页面、预览缓存复用、替换已有 m115 编解码依赖。不新增网盘写操作，写请求调度框架不为尚不存在的消费者预建。

## 验收基线

- S-AC1（S-R2、S-R6）：现有扫码绑定、账号读取、目录浏览、STRM 生成/302 播放和存量数据保持可用；无需数据库迁移。允许为抽样预览更新 OpenAPI、生成类型、前端解码/标签与相关测试，其他页面不改版。
- S-AC2（S-R3、S-R5、S-R7）：通过可控时钟/模拟上游验证限速、并发准入、播放与扫描调度、429/Retry-After、退避、最大尝试数、取消等待与凭据变化；网络故障不被误报授权失效。
- S-AC3（S-R8、S-R10）：标准与快速扫描在相同模拟目录树产出相同候选、路径和排除结果；覆盖空库、深层目录、分页变化、重复/缺页、缺失祖先、目录环、错误根目录和非递归设置。不完整快照不进入落盘，标准扫描仍按完整目录采用结果。
- S-AC4（S-R7、S-R8）：模拟上游证明快速列表请求量随文件/目录分页增长，不随每个子目录增长；限流/授权/取消不触发额外快速到标准重扫。非公开能力不支持时仅进行一次标准降级，公共分页上限不变。
- S-AC5（S-R2、S-R9、S-R11）：验证抽样最多 3 目录、5 次实际上游请求（含重试）、15 秒及 20 条样例，边界达到后不再发送请求；预览不触发整树快速扫描、不写文件/登记产物。前端明确区分抽样计数与全库总量，抽样未发现视频不能推断全库为空，也不能因此阻止合法提交。确认后才进行完整枚举。账号切换、所有权、恢复和既有播放 URL 的回归通过。
- S-AC6（S-R1、S-R4、S-R5）：所有新增/改动代码具有中文职责和主要方法说明；日志脱敏、层级聚合与错误归属通过检查，保持标准 TLS/HTTPS 与可信播放目标校验。
- S-AC7：通过格式、vet、单元/集成、race、lint、生成一致性和生产构建/冒烟等适用门禁；模拟与真实网盘结果分别报告，不进行无界高频实盘扫描。
